## Case conventions

Input tuple is **E/V/M**, categorical score points (no physical units). `∅` means no selection; `NT` means a selected untestable observation. Each ordinary calculation dispatches a final change event after selecting the stated values. The all-missing case uses an unselected-control change event in the fixture to exercise the empty branch. Injection cases alter the selected radio value in the fixture; ordinary radio options do not offer these values.

Fresh fixture per case; values are literal strings. Numeric cases use Calculate; GCS uses selection/change. Alerts absent from a recorded step mean none emitted. Event-only snapshots do not assert a browser render. PENDING is used wherever the reviewed sources do not establish a complete expected validator, presentation, recovery or clinical response. All states/labels below are **actual software text**, not approved recommendations.
