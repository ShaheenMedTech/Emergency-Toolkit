## Case conventions

Input tuple order is **RR / SpO₂ / SBP / pulse / temperature / scale / oxygen / consciousness**. Units: breaths/min, %, mmHg, bpm, °C; final three are categorical controls. Scale 1 or 2; oxygen 0=air, 2=supplemental; consciousness 0=Alert, 3=new confusion/CVPU. `∅` is an empty control. Scale2 arithmetic rows are conditional on established eligibility, not a claim that the inputs establish eligibility. Actual component vector is **[R,S,B,P,T]**, the five displayed scores; expected vector **[R,S,O,B,P,C,T]** also includes oxygen/consciousness.

Fresh fixture per case; values are literal strings. Numeric cases use Calculate; GCS uses selection/change. Alerts absent from a recorded step mean none emitted. Event-only snapshots do not assert a browser render. PENDING is used wherever the reviewed sources do not establish a complete expected validator, presentation, recovery or clinical response.
